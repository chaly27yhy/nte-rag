这个程序能做什么

        

          它是一本放在你自己电脑上的《异环》资料库：资料已经打包在程序里，不联网也能查；
          不够用的时候再按需抓公开网页补上，并把抓到的原文存进本地库，下次直接用。
        

        
    
          
  • 问答：直接问角色、剧情、地图、战斗、活动相关的问题，回答会附上来源链接，点开就能核对。
    • 
          
  • 知识库：分「知识条目」与「原始资料」两栏浏览已入库的内容，每条都能看到可信度、来源域名与抓取时间，
            也可以手动补录一条，或删掉不需要的。
    • 
          
  • 自动更新：按主题抓公开网页补资料，能看到每轮更新报告，把不想再抓的站点加进来源黑名单。
    • 
          
  • 设置：接自己的模型 API、调检索与质量参数、换壁纸、安排自动更新计划。
    • 
          
  • 内置资料：8 个公开站点的 70 篇文档、685 条知识条目与 152 段原文摘录（2026-09 的快照）。
            其中 1 篇已复核判为整页造假、导入时会被跳过，所以程序里实际看到的是 69 篇 / 150 段 / 682 条。
    • 
        

      

      

        
关于这个项目

        
    
          
  • 主要方向是「自带大模型 API」：把你自己的模型服务接进来做《异环》问答。预置 17 家服务商，
            也可以指向本机的 Ollama / LM Studio / vLLM，那样连模型调用都不出网；内置中文资料库是它的知识底座。
            不配模型时程序退化为「本地资料直出」，只展示检索到的原文片段，那是备用路径。
    • 
          
  • 作者单人维护的第一个开源项目：issue 和 PR 都会看，但不承诺响应时间。
    • 
          
  • Windows 专用，资料只有中文：原生窗口依赖 WebView2，打包脚本是 PowerShell；
            内置来源与界面文案都以中文为主，英文提问能跑，但多半找不到可用资料。
    • 
          
  • 开发过程用了 AI 编程助手：DeepSeek Harness 配合 DeepSeek v4.1-Flash 参与了代码实现、
            排查与文档整理；资料取舍与发布决定由作者负责。
    • 
          
  • 欢迎反馈：资料有错、来源失效、功能缺陷或纯粹是建议，都欢迎到项目仓库提 issue。
    • 
        

      

      

        
资料会过期

        
    
          
  • 内置资料是 2026-09 的快照，游戏更新后部分内容会滞后；个别来源也可能停更或下线。
    • 
          
  • 条目上的可信度是算出来的（来源等级 / 提取方式 / 多源一致性 / 时效），不是模型自评。
    • 
          
  • 抓不到页面或站点改版时，程序会明确报错并写进更新报告，不会编答案填空。
    • 
          
  • 复核发现整页造假的来源会按页面撤回：它的原文切片与条目一起退出检索（记录留在库里备查），
            所以答案里不会出现已经被推翻的说法。
    • 
          
  • 版本、数值、活动时间一律以游戏内与官方公告为准，本工具的资料只作参考。
    • 
        

      

      

        
运行信息

        

      

      

        
你的数据在哪、会发给谁

        
    
          
  • 只在你自己的电脑上运行：服务只监听 127.0.0.1，不对局域网或外网开放；每次启动换随机端口与一次性临时令牌。
    • 
          
  • 你的 API Key 只在你本机：用 Windows 自带的加密接口（DPAPI）保存，只有当前 Windows 账户能解开；界面回显一律打码（如 sk-1****abcd），日志里的密钥也会自动打码。
    • 
          
  • Key 只会发给你自己选的服务商：问答时请求直接由你的电脑发往该服务商；本程序没有中转服务器，也不会把 Key 发给任何第三方。
    • 
          
  • 没有统计与上报：不收集使用数据、不做设备指纹，也没有崩溃上报。
    • 
          
  • 抓取守规矩：抓网页前先看目标站点的 robots.txt，被明确禁止的地址会跳过并在更新日志里写明原因；
            站点没写（或只放了个空文件）就等于没有规则，按允许处理。字词/字典站与视频页在预置黑名单里，直接不抓；
            社区来源的页面还要求标题或正文里出现主题词，免得抓回跟《异环》无关的内容。
    • 
        

      

      

        
便携使用

        

          在 exe 同目录放一个名为 portable.flag 的空文件，数据和知识库就会保存在该目录下的
          data 文件夹里，整个文件夹拷到 U 盘即可带走（含已抓取的知识库）。
          不放该文件时，若 exe 所在目录可写也会自动使用便携模式；否则回落到 %APPDATA%\NTE-RAG。
